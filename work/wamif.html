03 / Maps + family history

Relationships, places, and time.

WAMIF explores ways to make family history navigable through the intersection of genealogical relationships, timelines, and location-based views.

The idea

Conventional family trees can make it hard to perceive how family relationships move through places and time. WAMIF approaches genealogical information as a connected, explorable data experience.

Technical direction

The project explores GEDCOM-based family history data and mapping-oriented visualizations. The current implementation and privacy-safe demonstrations are being curated for public review, so individual stack and deployment claims have deliberately been left off this page until a shareable evidence packet is ready.

Current status

Work in progress. The linked public repository currently provides limited implementation evidence and should not be treated as a complete technical demonstration. No live production deployment or validated use metrics are asserted here.

Privacy matters

Personal genealogical data and private source material will not be exposed merely to supply portfolio examples. A sanitized example, technical walkthrough, or openly accessible demo can be added once verified.
